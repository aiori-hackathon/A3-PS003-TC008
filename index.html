Detailed Specification

1. Local Preprocessing — 12-Hour Sliding Window

Each physical junction collects continuous sensor counts. Sequences are formatted into 12-hour historical sliding temporal windows locally without external broadcast.

Key Telemetry 48,120 Total Data Hours
GDPR / Privacy Compliant

100% Privacy Preservation

Raw traffic count data never leaves the local junction node. Only abstracted encrypted gradient weight updates are communicated.

Heterogeneity Aware

Non-IID Drift Resiliency

Designed specifically to mitigate local statistical distribution skew between heavy highway axes and quiet residential side-lanes.

Edge IoT Optimized

Minimal Bandwidth Footprint

Consuming just ~108 KB per communication round, FedTraffic operates seamlessly over low-bandwidth cellular/IoT edge hardware.
